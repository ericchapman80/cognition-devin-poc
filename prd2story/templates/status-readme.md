# Story Status Trackers

This directory contains status tracker files for each Epic.

Each tracker shows the current state of all stories in an Epic:

| Status | Meaning |
|--------|---------|
| `Pending` | Story identified but not yet written |
| `Generated` | Draft written to `stories/drafts/` |
| `Approved` | Moved to `stories/approved/` |
| `In JIRA` | Issue created; file in `stories/created-in-jira/` |
| `Skipped` | User chose to skip this story |

Check status at any time by asking: *"Show me the status of the [Epic name] Epic."*
